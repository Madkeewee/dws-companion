# DWS Companion public dashboard

Open index.html to preview the dashboard. This is a static browser replica of the Windows app, populated with the account snapshot exported in data.js. It includes the saved profile sections, heroes, formations, research, progress history, review entries, and workstation values.

## GitHub Pages

Upload the contents of this folder to your repository. In Settings > Pages choose Deploy from a branch, then your default branch and / (root). Save and open the published URL shown there.

Capture and scan controls are provided by the Windows app. This website displays the bundled snapshot and is read-only. The export contains public in-game statistics and excludes original capture images, diagnostics, and local file paths.
